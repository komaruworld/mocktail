Mocktail

Play Roblox on Linux. Use the stable Flathub release, or try the latest nightly build from main. Nightly Flatpaks are available for x86_64 and aarch64; Roblox runtime support on aarch64 is experimental.

Stable on Flathub Nightly build

Stable

flatpak install flathub space.bigrat.mocktail

Nightly

flatpak install --user https://mocktail.bigrat.space/mocktail.flatpakref

x86_64 nightly Flatpak aarch64 nightly Flatpak

AUR packages

Available from the AUR. Choose one package:

mocktail mocktail-bin mocktail-git

yay -S mocktail yay -S mocktail-bin yay -S mocktail-git

DNF repository

Stable and nightly packages for Fedora 44. Choose one package.

sudo curl -fsSL https://mocktail.bigrat.space/rpm/mocktail.repo -o /etc/yum.repos.d/mocktail.repo

Stable

sudo dnf install mocktail

Nightly

sudo dnf install mocktail-nightly

APT repository

Stable and nightly packages for Ubuntu 26.04. Choose one package.

sudo install -d -m 0755 /etc/apt/keyrings sudo curl -fsSL https://mocktail.bigrat.space/mocktail-packages.gpg -o /etc/apt/keyrings/mocktail.gpg echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/mocktail.gpg] https://mocktail.bigrat.space/apt mocktail main" | sudo tee /etc/apt/sources.list.d/mocktail.list >/dev/null sudo apt update

Stable

sudo apt install mocktail

Nightly

sudo apt install mocktail-nightly
